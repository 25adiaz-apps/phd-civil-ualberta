# Comprensión de artículos

Un notebook por artículo para entenderlo a fondo: problema, propósito, metodología, procedimiento y resultados, explicados paso a paso con fórmulas, código, gráficas y esquemas.

```
undestanding-papers/
├── requirements.txt                          Librerías comunes de los notebooks
└── AAAA-apellido-descripcion-corta/          Una carpeta por artículo
    ├── AAAA-apellido-descripcion-corta.pdf   El artículo
    └── AAAA-apellido-descripcion-corta.ipynb Explicación del artículo
```

Las reglas de nombres, estructura del notebook y forma de explicar están en [`CLAUDE.md`](../../CLAUDE.md), sección *Comprensión de artículos*.
