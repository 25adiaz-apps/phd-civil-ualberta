Contents
--------
Main.ipynb   Complete notebook with all analysis (Parts A-F and the AI-use note).
phase2_modal_parameters.json
             Input data (intact, damage1, damage2).
figures/     Figures generated by Main.ipynb, one subfolder per part:
               part-a/  Frequency, mode shape and MAC distributions
               part-b/  Wasserstein distances
               part-c/  Bivariate distributions and Mahalanobis detection
               part-d/  4-feature combination testing
               part-e/  PCA (scree plot, PC1, PC1-PC2, k components)
results/     Tables generated by Main.ipynb (CSV).

How to run
----------
Main.ipynb reads phase2_modal_parameters.json from its own folder or, if it is
not there, from the parent folder. Run all cells.
Requires Python 3, numpy, scipy (>= 1.13), matplotlib and pandas.
